## 🚀 Overview

**Axen** is a high-end **3D interactive landing page** built with **Next.js**, **GSAP**, and **Tailwind CSS**.  
The goal was to recreate an immersive, modern landing experience with **scroll-triggered animations**, **parallax effects**, and **3D motion interactivity** — all optimized for performance and responsiveness.

This project is perfect for showcasing animation-heavy front-end capabilities and advanced UI design workflows.

---

## 🧠 Features

- 🎞️ **Scroll-triggered animations** powered by GSAP for cinematic transitions  
- 🧩 **3D hover and motion effects** to add interactive depth  
- 🌀 **Clip-path transitions** for geometric section reveals  
- 💎 **Next.js optimized build** for smooth rendering and routing  
- 📱 **Fully responsive** across all screen sizes  
- 🧰 **Clean, modular component structure** with reusable utilities
